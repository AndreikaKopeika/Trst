# 🐔 Chicken Blocks

Мультиплеерная стрелялка про куриц с автоматами в мире из блоков (как Minecraft):
ломай и строй, укрепляй базу и защищай своё Золотое Яйцо. Две команды, долгие бои.
Работает прямо в браузере телефона, на весь экран, без установки и без своего сервера.

## Как играть с другом

1. Открой игру на телефоне (ссылка GitHub Pages, см. ниже).
2. Ты: «Создать комнату» → появится код из 4 символов. В меню ☰ есть кнопка «Ссылка» — отправь её другу.
3. Друг: открывает ссылку (код подставится сам) или вводит код → «Войти».
4. Выберите команды: вместе против ботов или друг против друга.

Соединение идёт напрямую между телефонами (WebRTC через PeerJS), сервер нужен только чтобы найти друг друга.
Телефон того, кто создал комнату, — «хост»: на нём считаются боты и урон. Если хост свернёт браузер, игра встанет.

> Для настоящего полного экрана на iPhone: «Поделиться» → «На экран Домой» и запускать с иконки.

## Цель

У каждой команды на базе стоит Золотое Яйцо. Разбей вражеское — раунд твой. После этого генерируется новая карта.

## Оружие

| Слот | Оружие | Особенность |
|---|---|---|
| AK | Автомат | универсальный |
| ПКМ | Пулемёт | 80 патронов, долгая перезарядка |
| СВД | Снайперка | оптика, ваншот в голову, пробивает стекло |
| КОРД | Тяжёлый пулемёт | раскрутка стволов, крошит стены, замедляет |
| ДРОБ | Дробовик | 9 дробин, вблизи страшен |
| РПГ | Базука | ракета, взрыв рушит блоки, можно делать ракетные прыжки |
| — | Гранаты | 3 штуки на жизнь, отскакивают |
| БЛОК | Стройка | ставить и ломать блоки |

## Блоки

Разная прочность: стекло и листва лопаются от пули, доски держат пару очередей, кирпич и бетон крепкие,
сталь очень прочная и даёт рикошеты, мешки с песком гасят взрывы, ТНТ взрывается от выстрела (цепные реакции!).
Блоки для стройки стоят «кирпичики» (🧱) — их дают за разрушенные блоки и убийства.

## Управление

**Телефон:** левая половина экрана — джойстик, правая — обзор пальцем. Большая красная кнопка — огонь
(её можно тянуть, чтобы целиться не отпуская), слева есть вторая кнопка огня. Прицел, прыжок
(держи в воздухе — курица планирует), перезарядка, граната, режим стройки.

**ПК:** WASD, мышь, пробел, R — перезарядка, G — граната, Q — стройка, 1–7 — оружие, F/ПКМ — прицел,
колесо — смена оружия/блока, V — вид от 1-го лица, Tab — счёт.

## Как выложить игру (GitHub Pages)

Игра — это статические файлы, сборка не нужна.

1. Репозиторий должен быть публичным (на бесплатном аккаунте Pages работает только с публичными):
   Settings → General → Danger Zone → Change visibility → Public.
2. Settings → Pages → Source: **Deploy from a branch** → ветка с игрой, папка `/ (root)` → Save.
3. Через минуту игра будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Локально: `npx http-server .` и открыть `http://localhost:8080`.
Отладка мультиплеера в одном браузере: добавь `?local=1` к адресу и открой две вкладки.

## Устройство

- `js/world.js` — воксельный мир 112×40×60, генерация карты с базами, рейкаст, коллизии
- `js/mesher.js` — меши чанков 16³ с ambient occlusion, перестраиваются с бюджетом по времени
- `js/game.js` — игроки, стрельба, стройка, сеть (хост — авторитет по урону и блокам)
- `js/bots.js` — ИИ ботов: маршрут к вражескому яйцу, бой, пробивание стен, столбы из блоков
- `js/fx.js` — частицы, обломки, трассеры, дырки от пуль, вспышки, взрывы
- `js/audio.js` — все звуки синтезируются WebAudio
- `js/net.js` — PeerJS (WebRTC) и локальный режим для отладки
- `js/lib/` — three.js r160 и PeerJS 1.5.4
